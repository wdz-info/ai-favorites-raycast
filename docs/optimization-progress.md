# 自用优化实施清单

依据：2026-10-18 调研文档，自用目标；基线 0.3.0 / c6ad1d2。

当前版本 0.5.2；下列优化及网页功能已随 [c044abf](https://github.com/wdz-info/ai-favorites-raycast/commit/c044abfffba83988033aec3596dc7de46dc0181b) 提交至 GitHub。安装和更新见 [README](../README.md)，版本变化见 [更新记录](../CHANGELOG.md)。

- [x] 共享检索：相关性、验证筛选、失效折叠、项目/版本范围、命中片段。
- [x] 历史全文索引：三个现有 Provider、增量更新、会话去重、消息/上下文定位、失败保留、永久快照独立。
- [x] Raycast 统一入口：收藏和历史分区、即时查询、原文展开、收藏命中回复。
- [x] 快捷保存：剪贴板命令、默认标题、可稍后补充来源和备注、从历史一键保存。
- [x] 上下文复用：完整/片段/代码模式、预算、去重、排除条目/路径、验证状态、复制。
- [x] 复用反馈：这次有用/未解决，独立于人工验证。
- [x] 备份与恢复：预览、新条目合并、ID 冲突保留双方、原快照不覆盖。
- [x] CLI：检索、按 ID 分页读取、打包，复用核心服务。
- [x] MCP：官方 SDK、stdio、三个只读工具、分页与长度预算、真实客户端协议测试。
- [x] 自然语言/模糊检索：显式词项扩展；可选本地嵌入、失败回退、查询对照评估。
- [x] 文档与验证：匹配变更的回归测试、类型/格式/构建、只读本机数据 smoke；记录未实测的桌面/模型边界。

- [x] 追加目录收藏：中文 `file://`、目录 / index.html 入口、完整二进制资源快照、独立版本、删除源后打开、备份恢复与 Obsidian 配套资源导出。
- [x] 网页管理：Raycast 快捷启动、共用资料库、阅读与编辑、版本与验证、上下文包和备份恢复。
- [x] 历史添加修复：弹窗内加载、搜索与分页，失败重试，成功打开后关闭，保存后展示新收藏。
- [x] 网页历史分类：程序 → 今天 / 昨天 / 历史，覆盖浏览页与添加弹窗，分类计数及分类内搜索 / 分页。

验证证据见 [实现与验证记录](../VALIDATION.md)；检索对照数据见 [search-evaluation-0.4.json](search-evaluation-0.4.json)。本地嵌入完成接口、缓存和回退验证，实际模型质量未验证，仍为可选实验功能；原生桌面验收由使用者安排，不占用当前桌面。

Agent 适配继续按实际使用需求增加。模型服务由使用者配置，不自动下载模型；MCP 配置由使用者添加。当前待验收项仍以验证记录为准。
