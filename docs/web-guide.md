# 网页收藏夹使用指南

适用于 0.5.2。网页与 Raycast 读写同一份收藏资料库。首次安装见 [README](../README.md#本地安装)，版本变化见 [更新记录](../CHANGELOG.md)。

## 打开网页

在 Raycast 运行“打开网页收藏夹”，命令会启动或复用本地服务，并在默认浏览器打开页面。可在 Raycast 设置中给命令配置全局 Hotkey；在收藏操作菜单按 ⌘⇧O 也可打开网页。“在网页中阅读这条收藏”会直接定位对应条目。

网页沿用 Raycast 配置的收藏目录和 Agent 历史目录。关闭浏览器后服务继续运行，侧栏“停止网页服务”可关闭服务，下次从 Raycast 打开时重启。

终端入口会输出访问链接，需自行在浏览器打开：

```bash
npm run web
# 使用自定义收藏资料库
npm run web -- --storage /绝对路径/收藏资料库
```

终端的 `--storage` 选择收藏资料库；自定义历史目录通过 `CODEX_HOME`、`GROK_HOME`、`KIRO_HOME` 指定，不会读取 Raycast 的扩展设置。网页使用随机端口和带凭证的启动链接；服务重启后，从启动入口重新打开。

## 按程序和时间浏览历史

点击侧栏“浏览历史会话”，选择程序，再选择时间。只显示历史目录中发现的程序，当前适配 Codex、Grok、Kiro。

```text
全部程序
Codex
  今天
  昨天
  历史
Grok
  今天
  昨天
  历史
Kiro
  今天
  昨天
  历史
```

点击程序名查看该程序的全部时间，点击“全部程序”清除程序和时间筛选。中间列表也按程序、时间显示分组标题。

| 分类 | 判断方式                               |
| ---- | -------------------------------------- |
| 今天 | 会话最近更新时间位于北京时间当天       |
| 昨天 | 会话最近更新时间位于北京时间前一自然日 |
| 历史 | 其余会话                               |

时间使用 `Asia/Shanghai`，按自然日划分。例如北京时间 10 月 18 日凌晨 1 点，10 月 17 日零点更新的会话仍属于“昨天”，即使已超过 24 小时。较早创建但今天继续对话的会话会归入“今天”。

顶部搜索按会话标题、项目路径和 ID 匹配，再在所选分类内展示结果；搜索历史回复正文使用 Raycast 的“搜索收藏”。每页最多 40 条，翻页保留分类，切换分类重置到第一页。分类旁的数量统计全部匹配会话，包含尚未翻到的页面。

## 从历史添加收藏

1. 点击“添加收藏”→“从历史会话添加”。
2. 在弹窗内选择程序和时间，需要时搜索标题、项目或 ID。
3. 点击会话，成功读取后弹窗关闭，阅读区显示会话内容。
4. 选择“收藏整个会话”或某条 AI 回复的“收藏这条回复”，填写标题、标签、备注后保存。

回复快照保留对应用户问题，收藏后可独立阅读。保存完成后页面转到全部收藏并清除旧筛选，方便看到新条目。也可直接从“浏览历史会话”进入同一收藏流程。

加载期间弹窗保持打开，失败会显示提示并允许重试。连续操作复用 15 秒内的目录扫描；刚生成的会话未出现时，点击“刷新历史”重新扫描。若仍为空，检查 Raycast 的历史目录设置，以及该程序是否已生成支持格式的本地记录；Grok 网页聊天不在当前历史来源中。

## 收藏文件或整个网页目录

“添加收藏”→“文件 / 目录”接受本机绝对路径或 `file://` 链接，包括中文路径的转义形式，例如：

```text
/Users/example/notes/指标说明/index.html
file:///Users/example/notes/%E6%8C%87%E6%A0%87%E8%AF%B4%E6%98%8E/index.html
```

选择 `index.html` / `index.htm` 会保存其所在目录；选择目录会自动查找入口页。快照包含图片、CSS、JavaScript 和数据等资源，可通过“打开网页 / 目录快照”阅读。源目录随后修改或删除，已保存版本仍可打开；再次收藏变化后的目录会保留独立版本。

单个文本文件上限 8 MiB，目录上限 64 MiB / 2000 个文件，不跟随符号链接。目录外的在线资源和服务端接口不随快照保存，仍依赖原服务。

## 管理、复用和备份

全部收藏支持按来源、类型、项目、标签、验证状态筛选，搜索正文、问题和备注。阅读区可复制、编辑元数据、记录验证和使用反馈，或比较已收藏版本。列表多选后可预览并复制上下文包。

侧栏可下载完整 JSON 备份，包含目录资源。恢复时先上传检查、阅读预览，再确认合并；已有快照保留，ID 冲突会保留双方内容。网页上传上限 128 MiB，更大的备份使用 Raycast 的本地恢复入口。

## 更新已有安装

在源码目录停止旧的 `npm run dev`（若仍运行），然后执行：

```bash
git pull --ff-only
npm ci
npm run dev
```

等 Raycast 完成编译和扩展导入，再运行“打开网页收藏夹”。启动入口会检测构建变化并替换旧服务，旧浏览器标签页需重新打开。开发监听可在导入完成后停止。

收藏保存在配置的资料库目录，不在源码构建目录；默认是 `~/Library/Application Support/AI Favorites`。更新前可从网页下载备份。只改网页源码时，先运行 `npm run build:web`，再重新加载扩展并打开网页。

## 常见情况

| 现象                       | 处理方式                                                                               |
| -------------------------- | -------------------------------------------------------------------------------------- |
| 旧页面断开或显示未授权     | 从 Raycast 重新运行“打开网页收藏夹”，使用新的启动链接                                  |
| 提示网页服务尚未构建       | 在源码目录运行 `npm run build:web`，再重新加载扩展                                     |
| 服务启动失败               | 检查资料库中的 `web-service.log`；服务应在约 10 秒内就绪                               |
| Raycast 与网页显示不同收藏 | 确认使用同一收藏目录，尤其是终端的 `--storage`；网页重新获得焦点或等待 15 秒会刷新列表 |
| 历史会话不在预期日期       | 按最近更新时间、北京时间判断；点击程序名可查看该程序的全部时间                         |

`web-service.json` 含本机访问凭证，排查问题时不要公开该文件或完整启动链接。分享收藏内容可使用导出或备份功能。
